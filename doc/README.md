# Riset persiapan SAUVC 2027

Tanggal pemeriksaan: **1 Oktober 2026**. Bahasa: Indonesia.

Folder ini mengumpulkan temuan dari penyelenggara, institusi peserta, pengembang perangkat lunak, publikasi riset, produsen, dan otoritas perjalanan. Ini adalah catatan riset yang dapat diperbarui, bukan rulebook pengganti.

**Temuan utama:** SAUVC 2027 diumumkan berlangsung **24–27 Februari 2027 di Singapore Polytechnic**. Halaman aturan dan manual yang tersedia masih memuat edisi sebelumnya. [Situs resmi](https://sauvc.org/)

Label yang digunakan:

- **Terkonfirmasi 2027:** dinyatakan dalam pengumuman penyelenggara untuk 2027.
- **Referensi historis:** benar untuk sumber/edisi yang disebut, belum menjadi ketentuan 2027.
- **Klaim peserta:** laporan tim/pembuat, belum tentu diverifikasi panitia.
- **Usulan internal:** analisis atau rencana hasil riset, bukan instruksi panitia.
- **Belum ditemukan:** tidak ditemukan dalam penelusuran ini; bukan bukti bahwa informasi tidak tersedia di semua kanal.

Ringkasan disimpan sebagai parafrasa dengan tautan sumber. Sumber web tidak disalin utuh. Dua PDF yang diberikan pengguna disimpan utuh di `sources/` sebagai arsip lokal. Kode, dataset, dan simulator belum dijalankan atau divalidasi pada perangkat tim.
