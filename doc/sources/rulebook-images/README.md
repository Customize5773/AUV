# Gambar rulebook SAUVC

**19 gambar** dari [rulebook resmi](https://sauvc.org/rulebook/) edisi **2026, v6.1.0**, diambil 1 Oktober 2026. Bukan konfirmasi arena/aturan 2027.

Buka [galeri lokal](galeri.html) untuk melihat seluruh gambar; klik gambar untuk membuka resolusi aslinya. Nama berkas asli dipertahankan, tanpa resize atau konversi. [Manifest](manifest.json) mencatat URL, bagian dokumen, dimensi piksel, ukuran berkas, dan SHA-256.

Unduhan langsung situs mengembalikan HTTP 403. Berkas diambil dari [repositori resmi SAUVC](https://github.com/sauvc/rulebook), commit `1caf29cf132318b9b5fc81b7a73ac772db9fbca0`. Daftar 19 rujukan gambar cocok dengan urutan/jenis gambar pada halaman web. Kesetaraan byte terhadap berkas yang disajikan server web belum diuji.

Tanggal pembaruan tidak sinkron: halaman web menampilkan 27 November 2025, sedangkan metadata sumber repositori menampilkan 15 Mei 2026; keduanya v6.1.0. Perbedaan ini dipertahankan dalam manifest.
